# NeoCode

Plataforma de desafios de programação desenvolvida no âmbito da Prova de Aptidão Profissional (PAP). O objetivo é permitir que os utilizadores pratiquem JavaScript através de desafios, ganhem pontos e compitam num ranking.

## 🚀 Tecnologias

- HTML
- CSS
- JavaScript
- PHP
- MySQL
- Node.js
- XAMPP
- Monaco Editor

## ⚙️ Funcionalidades

- Sistema de registo e início de sessão
- Desafios de programação em JavaScript
- Editor de código integrado
- Execução de código através do Node.js
- Sistema de pontuação, com 100 pontos por desafio concluído
- Ranking de utilizadores
- Base de dados para gerir utilizadores, desafios e submissões
- Interface com tema hacker, animação de código binário e cores verdes

## 🛠️ Estado do Projeto
