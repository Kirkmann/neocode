# NoeCode - Instruções de Instalação

## Requisitos
- **XAMPP**: Servidor web com Apache e MySQL.
- **Node.js**: Para executar desafios em JavaScript.

## Instalação do Node.js
1. Acesse https://nodejs.org/ e faça download da versão LTS (Long Term Support).
2. Siga as instruções de instalação:
   - **Windows**: Marque "Add to PATH" durante a instalação.

## Base de dados 

- Nome da base de dados: neocode
